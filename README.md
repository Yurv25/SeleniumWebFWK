# Selenium Test Automation Framework

Basic test automation framework built using **Java**, **Selenium WebDriver**, and **JUnit**.

## Overview
This project demonstrates a simple UI test automation setup following the **Page Object Model (POM)** design pattern. It is intended to show test structure, separation of concerns, and reusable components for web testing.

## Tech Stack
- Java
- Selenium WebDriver
- JUnit

## Features
- Page Object Model (POM) structure
- Basic test cases using JUnit
- WebDriver setup and browser interaction
- Reusable page classes

## How to Run
1. Clone the repository  
2. Open in your preferred IDE
3. Run test classes using JUnit  

## Notes
This is a work in progress project created to practice and demonstrate test automation concepts.
